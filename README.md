# William | Web Developer

React + Vite portfolio website.

## Run in VS Code

1. Install Node.js (LTS) if you haven't already.
2. Open this folder in VS Code.
3. Open Terminal and run `npm install`.
4. Run `npm run dev`.
5. Open the localhost address shown in the terminal.

## Before publishing

- In `src/main.jsx`, replace `YOUR_EMAIL@example.com` with your real business email. The enquiry form opens the visitor's email app; it does not submit to a server.
- Replace the three clearly labelled **concept projects** with real screenshots and links when you have them. The examples are mockups, not deployed client projects.
- Check pricing and scope, especially custom functionality, hosting, and third-party costs.
- Update the text and add your own domain when ready.

## Build

`npm run build` generates a production-ready `dist` folder for hosting.
